Open Source Android Audio Tool

LV2 guitar processing on a phone, without the toy feel.

opiqo turns an Android device into a real-time guitar multi-effects processor with a four-pedal chain, low-latency audio through Google Oboe, bundled LV2 effects, preset backup and restore, and direct recording in WAV, MP3, Opus, FLAC, and OGG Vorbis.

Signal Path

Guitar / microphone input ↓ Oboe full-duplex audio stream ↓ LV2 pedal 1 → 2 → 3 → 4 ↓ Master gain and recording ↓ Speaker, headphones, or interface output

Built for real audio work

The project is not a skin over canned effects. It is an Android LV2 host with native processing, dynamic plugin loading, per-pedal bypass, hardware device selection, and preset portability.

Native audio engine

Audio processing runs in C++ with Google Oboe and a full-duplex engine designed for low-latency real-time work on Android 12 and newer.

Real pedal-chain workflow

Swipe across four pedal slots, load LV2 effects per slot, bypass them independently, and delete or replace plugins without rebuilding the chain.

On-device recording

Capture the post-effects signal directly from the app in multiple formats, including lossless WAV and FLAC plus compressed MP3, Opus, and OGG.

Preset import and export

Back up all saved presets to JSON, restore them with Android's document picker, and reload the pedal setup immediately after import.

Bundled guitar voices

The app ships with distortion, overdrive, fuzz, amp simulation, modulation, and filter plugins ready to use out of the box.

Inspectable and modifiable

MIT-licensed source, documented build steps, LV2 bundle structure, and native code exposed in the repository for anyone who wants to extend it.

How it works

Audio enters through the selected input device, crosses the JNI bridge into the native engine, and moves through up to four LV2 plugins before master gain and output routing.

Build requirements

Android 12+, JDK 11+, Android NDK, CMake 3.22.1+, and the included Gradle wrapper are the core prerequisites described in the project README.

  • Android Gradle Plugin 9.x with prefab support for Oboe
  • Native LV2 support through Lilv, Serd, Sord, Sratom, Zix, and JACK components
  • Debug and release builds available through Gradle tasks

Open source by design

opiqo is released under the MIT License. The Android app, native engine, LV2 hosting layer, and UI are all available in the public repository, which makes the project's behavior inspectable instead of opaque.

Need the data policy?
