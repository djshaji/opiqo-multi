Privacy Policy

How this project handles audio, files, and permissions.

This privacy policy applies to the opiqo Guitar Multi Effects Pedal for Android project. It describes the app's current data handling behavior as reflected by the open source project.

Effective date: March 22, 2026

Summary

In short, the app processes audio locally on your device and does not send your audio recordings, presets, or usage data to any remote service. Absolutely no data is collected or shared with anyone. This app does not contain any advertising, analytics, or crash reporting SDKs.

I am one of the old-school developers from the era before everything was a subscription.

I built this project to be a simple way for guitarists like me to use these plugins and get amazing tones, and I have no interest in collecting data or showing ads. This app is for the guitarist who's struggling to find that first gig. I feel you man. Keep on rocking. The app only requests microphone access to enable its core audio processing features, and all audio processing and file handling happens locally on your device. You can review the full privacy policy below for more details, and you can inspect the open source code yourself on GitHub to see exactly how the app works. If you have any questions or concerns, please feel free to reach out through the GitHub repository.

opiqo is designed to process audio on-device. The app requests microphone access through the RECORD_AUDIO permission so it can capture input audio for live processing and recording. The current project does not include advertising SDKs, analytics SDKs, or crash reporting SDKs.

Information the app can access

  • Microphone audio when you grant microphone permission and start audio processing or recording.
  • Files you explicitly choose through Android's document picker for preset import or plugin-related file selection.
  • Files created by the app on your device, such as recordings and saved presets.

Why microphone access is requested

The app is a guitar and audio effects processor. Microphone access is required so the app can capture input audio, pass it through the LV2 effects chain, and optionally record the processed output.

How audio and files are handled

  • Audio is processed locally on the device through the app's native engine.
  • Recordings are stored on-device in the format you choose.
  • Presets are stored locally and can be exported to a JSON file when you initiate an export.
  • Imported presets are read from a file you select and copied into the app's presets directory so they can be reloaded immediately.
  • Plugin-related files selected by you may be copied into the app's internal files area so the associated LV2 plugin can use them.

Data sharing

The current Android build is not described as sending your audio recordings, presets, or usage data to a remote service as part of normal operation. If you export files, those files go to the location you choose using Android's system file picker.

Third-party components

The project uses third-party open source components for audio and LV2 hosting, including Google Oboe and LV2-related libraries such as Lilv, Serd, Sord, Sratom, Zix, and JACK components. Those components support the app's local processing features, but this policy does not replace their own licenses or documentation.

Open source transparency

This project is open source and released under the MIT License. You can inspect the implementation yourself at github.com/djshaji/opiqo-multi. If the app's behavior changes in future releases, this policy should be updated to match.

Your choices

  • You can deny microphone permission, although core audio-processing features will not work without it.
  • You choose whether to record audio, export presets, import presets, or select plugin-related files.
  • You can remove recordings or exported files from your device using your normal file-management tools.

Changes to this policy

This page should be updated if the app's permissions, data flows, or third-party services change. For the latest project status, review the repository and release notes on GitHub.
